# iOS Configuration Guide

## CocoaPods Setup

The Podfile has been configured with proper Flutter integration. After any changes to `pubspec.yaml`, run:

```bash
cd ios
pod install
cd ..
```

## xcconfig Files

All Flutter xcconfig files are properly configured with CocoaPods includes:

- `Flutter/Debug.xcconfig` - Includes `Pods-Runner.debug.xcconfig`
- `Flutter/Release.xcconfig` - Includes `Pods-Runner.release.xcconfig`
- `Flutter/Profile.xcconfig` - Includes `Pods-Runner.profile.xcconfig`

### firebase_app_id_file.json (Optional)

The warning about `firebase_app_id_file.json` is not critical. This file is generated by `flutterfire configure` and is used by some Firebase CLI tools, but it's not required for the app to function.

If you need to generate it:

```bash
flutterfire configure --project=vidhata-811df
```

This will create `firebase_app_id_file.json` in the project root. The file is already added to `.gitignore` as it's environment-specific.

## Troubleshooting

### CocoaPods Warning About Base Configuration

If you see:
```
[!] CocoaPods did not set the base configuration...
```

This is resolved by ensuring all xcconfig files include the Pods xcconfig files (which they do). If the warning persists:

1. Clean the build:
   ```bash
   cd ios
   pod deintegrate
   pod install
   ```

2. Verify xcconfig files include Pods configuration:
   - Check `Flutter/Debug.xcconfig`
   - Check `Flutter/Release.xcconfig`
   - Check `Flutter/Profile.xcconfig`

3. Ensure Xcode project references the correct xcconfig files in Build Settings.

### Firebase Initialization Issues

Ensure `AppDelegate.swift` contains:
```swift
import Firebase

FirebaseApp.configure() // Must be called before GeneratedPluginRegistrant.register
```
